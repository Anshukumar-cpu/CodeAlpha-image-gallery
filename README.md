# Vista — Image Gallery

A responsive image gallery built for the CodeAlpha Frontend Development internship task.

## Features
- Responsive HTML/CSS gallery layout for mobile, tablet and desktop.
- JavaScript category filters: All, Nature, Architecture and Travel.
- Live photo search by title, location or category.
- Lightbox image viewer with previous/next navigation.
- Keyboard support: Left/Right arrows to navigate and Escape to close.
- Hover effects and smooth transitions.
- Accessible button labels and focus styles.

## How to run
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. An internet connection is required to load the sample photographs and Google Fonts.

- CSS3
- Vanilla JavaScript

## Customization
To add or replace a photo, copy one of the `.gallery-card` button blocks in `index.html`, update its `data-category`, `data-title`, `data-location`, image URL and alt text. Use one of the existing category names or add a matching filter button.
